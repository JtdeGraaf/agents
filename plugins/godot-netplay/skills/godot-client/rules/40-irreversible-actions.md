# Rule: Irreversible actions ask first

The general rule is house-style's irreversible-actions rule. In a game:

| Action | Confirmation |
|---|---|
| Ending your own turn/attempt early, mid-action | Double press within a short window, with a HUD banner after the first press |
| Leaving while hosting with others connected | A confirm dialog — leaving ends the game for everyone |

- Keyboard-driven, mid-action flows use the double press; menu/panel actions use a confirmation dialog with a verb
  on the OK button ("Leave"), never plain "OK".
- Say what happens to **other** players in the dialog text.
- Actions that are cheap to undo (ready toggle, leaving as a non-host, rerolling in solo) don't ask.
- **Unsure whether something counts as irreversible? Ask before implementing it without a confirmation.**
