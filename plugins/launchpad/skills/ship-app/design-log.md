# ship-app design log

Every app shipped with ship-app, newest last. Each entry is an **anti-reference** for the next app:
a new app must not reuse an earlier app's world/concept, palette family, or typefaces.

Entry format:

```
## <slug> — <yyyy-mm-dd>
- Idea: <one line>
- World: <the visual concept / metaphor>
- Palette: <4–6 hex values with names>
- Type: <display face> / <body face>
- Signature move: <the one memorable thing>
- Mode: <Operate | Experience | Read | Persuade>
```
